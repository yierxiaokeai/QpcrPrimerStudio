# 设计参数

参数用于新设计与已有引物评估。最小、最佳、最大值需要按顺序设置；最佳值是优化目标。下面默认值对应内置工程预设，实际设置应与试剂体系一致。

简单模式的 Search 窗口提供搜索类型、F/R 范围、引物长度与产物长度；窗口下方摘要显示当前 Tm、GC 和返回数量。勾选“专业模式”可调整这些参数，并在工作台打开完整“设计条件”。切换模式保留当前设置，反应体系、结构限制与区域策略持续应用。综合分数及其证据在两种模式中均可查看。

## 检测目标与区域

| 参数 | 含义与使用条件 |
| --- | --- |
| 完整转录本 | 在输入转录本范围内规划候选区域，仍应用两端避让与其他约束。 |
| 仅 CDS 编码区 | 限定编码区，需要可信 CDS 注释。 |
| 5′ UTR / 3′ UTR | 限定对应非翻译区，需要注释；可用于寻找家族成员的差异区域。 |
| 优先 CDS 编码区 | 有注释时优先使用 CDS，具体使用区域与回退情况查看任务证据。 |
| 避开 UTR | 根据注释排除 UTR。 |
| 当前模板 | 针对当前输入序列设计。 |
| 基因总表达 | 根据参考项目中该基因的转录本关系寻找共有区域；覆盖范围受参考注释与纳入转录本集合限制。 |
| 转录本特异检测 | 搜索目标转录本独有区域或连接位点，并结合特异性结果检查。 |
| 指定转录本集合 | 按纳入的转录本集合规划共有检测区域。 |
| 避开两端 | 分别排除转录本 5′ / 3′端的指定 nt，默认各 50 nt；短序列可能因剩余区域过小而设计失败。 |
| 避让 SNP / Indel | 基于已提供且已投影的变异排除或惩罚候选，未提供变异时不能判定无变异。 |
| 排除末端变异 | 按“变异 3′末端窗口”硬性排除末端变异。 |
| 要求跨连接位点 | 至少一条引物跨已知 exon–exon junction；缺少连接位点时不能完成此约束。 |
| 自动检查特异性 | 对设计结果运行已配置数据库的检查；分别确认转录本和基因组数据库已配置。 |

## 引物与产物

| 参数 | 默认值 | 解释 |
| --- | --- | --- |
| 扩增子长度 | 80–200 bp | Forward 与 Reverse 围成的 cDNA 产物长度范围。 |
| 引物长度 | 18 / 20 / 24 nt | 最小 / 最佳 / 最大长度；过窄范围可能减少可用候选。 |
| 引物 Tm | 58 / 60 / 62 °C | 最小 / 最佳 / 最大预测熔解温度，受盐、Mg²⁺、dNTP 与引物浓度影响。 |
| 最大 Tm 差 | 2 °C | 同一对引物预测 Tm 的允许差值。 |
| GC 范围 | 40–60% | 单条引物 GC 含量约束。 |
| 候选数量 | 10 | 引擎请求返回的数量，允许 1–100；后续质量筛查可能减少保留数量。 |

## 智能推荐

Search Criteria 的“智能推荐参数”使用 Primer3 实际试算当前模板，优先采用表中的常规设置。没有保留候选时，依次检查最大 30 nt 的引物长度和 30–70% 的 GC 范围，并明确记录扩大项；Tm 窗口、结构限制和实际反应浓度保留。建议需点击“应用推荐参数”载入，再正式搜索。试算未包含数据库特异性检查。

“统一搜索参数用于本工程全部基因”同步公共设置和各靶标单独设置中的长度、Tm、GC、产物与数量，各基因区域及反应浓度保留。推荐保存模板与引擎指纹、每次原始输入输出和候选数量，随项目保存并恢复。

常规范围与 Tm 优化目标的依据可查阅 [Primer3 官方手册](https://primer3.org/manual.html) 和 [Thermo Fisher 引物设计指南](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/MAN0012618_Guidelines_Primer_Design_UG.pdf)。扩大搜索范围是本软件的回退策略，候选仍需特异性和实验检验。

## 反应体系与结构

| 参数 | 默认值 | 解释 |
| --- | --- | --- |
| 单价盐 | 50 mM | 热力学模型使用的单价盐浓度。 |
| Mg²⁺ | 1.5 mM | 反应中镁离子浓度。 |
| dNTP 总浓度 | 0.6 mM | 各 dNTP 合计浓度，参与有效镁离子相关计算。 |
| 引物浓度 | 250 nM | 模型使用的引物浓度；确认单位。 |
| 最大发卡结构 Tm | 47 °C | 发卡结构稳定性上限。 |
| 最大自二聚体 ANY Tm | 47 °C | 单条引物任意位置自互补的结构 Tm 上限。 |
| 最大自二聚体 END Tm | 35 °C | 涉及引物末端的自互补结构 Tm 上限。 |
| 最大异二聚体 ANY / END Tm | 47 / 35 °C | Forward 与 Reverse 任意位置 / 末端互补结构 Tm 上限。 |
| GC clamp | 0 | 要求 3′端的 GC clamp 数量；默认不强制。 |
| 连续相同碱基上限 | 4 | 限制引物内连续同一碱基的长度。 |

结构 Tm 使用 °C，结构分析中的 ΔG 使用能量单位，二者不可直接混用。ΔG 越负通常表示模型条件下结构更稳定；需要同时检查 3′互补、互补连续长度与反应条件。

## 坐标、变异与权重

- 连接位点：填写拼接 cDNA 上前一外显子的最后一位坐标，使用 1-based，多项用逗号分隔。例如 `120,260`。
- 两侧最小重叠：跨 junction 的引物在 5′侧 / 3′侧至少覆盖的 nt，默认 7 / 4。
- 包含区域：起点使用 1-based，长度单位 nt；长度 0 表示不额外限定整段长度。
- Forward / Reverse 搜索区域：分别限定两条引物结合区间，起点按输入序列 1-based 坐标填写，长度 0 表示不限。Reverse 坐标仍沿输入序列递增，序列显示为 5′→3′。单引物搜索使用所选方向的区域与包含区域的交集；成对设计同时应用两个区域和产物长度限制。
- Search Criteria 窗口使用“起点 — 末位”，包含末位；末位留空表示模板末端。例如 101–200 表示从第 101 到第 200 位，共 100 nt。设计条件页仍使用“起点 / 长度”。搜索类型为单引物时，产物长度与另一方向范围停用。
- 排除区域：格式为起点,长度，多段以分号分隔。例如 `1,30;150,20`。
- 预期转录本：输入数据库中的预期 subject ID，多项用逗号分隔；名称必须与数据库序列 ID 对应。
- 变异末端窗口：从引物 3′端向内计数的窗口长度，重点保护靠近延伸端的结合区域。
- 评分权重覆盖：输入 JSON 对象，只覆盖填写的指标，其余保留默认权重。查看质量报告确认指标名称与分项贡献。

```json
{"Tm":10,"ΔTm":10,"转录本特异性":30}
```

参数预设保存为可复用设置。“当前靶标专用参数”用于该靶标的独立覆盖。放宽条件后应重新查看证据与筛除原因，确认放宽项可以接受。
