# 参考与特异性

## 建立物种参考项目

准备同一版本的转录本 FASTA；如有基因组，加入 genome FASTA 和 GFF3 注释。按对话框提示提供 CDS、蛋白与 VCF 等可选资料，并记录物种名称、版本和来源。

软件解析 transcript ↔ gene、外显子、CDS 结构，并校验序列与坐标关系。导入完成后查看参考摘要与警告，再按 Gene / Transcript 添加靶标。ID 与注释关系异常需要先处理。

## 只有转录组时

转录组组装、TSA 或 CDS FASTA 可以作为输入。仍可设计引物、检查转录本命中并评价扩增子，但依赖实际数据内容。缺少基因组和结构注释时，外显子连接策略与基因组污染判断会受限；结果中对应状态显示不可用或未知。

## 两类特异性数据库

1. 转录本数据库：使用目标物种的转录本 FASTA 建库，检查其他基因、转录本及相似家族成员。
2. 基因组数据库：使用 genome FASTA 建库，检查额外结合位点与预测基因组产物。
3. 在数据库类型下拉框选择类别，再建立或打开对应数据库。确认摘要中的路径和版本。
4. 使用“检查当前候选”或“检查全部”，分别查看两类结果。自动检查使用已配置数据库。

## 搜索条件

| 参数 | 解释 |
| --- | --- |
| 总错配上限 | 纳入候选结合位点的总错配阈值；放宽后可能纳入更多非靶向命中。 |
| 末端 5 nt 错配上限 | 3′端最后 5 nt 的允许错配数，影响纳入命中的集合。 |
| 最大产物 | 成对扩增几何允许的最大产物 bp；过小可能漏掉较长基因组产物。 |
| 最大命中序列数 | 搜索命中 subject 的上限；限制会影响搜索完整性，需检查原始搜索证据与警告。 |

单条引物命中数量不能单独决定扩增风险。软件结合正反向方向、两结合位点间距、预测产物长度以及 3′错配位置等证据分析成对扩增。所有结果都受数据库覆盖与搜索限制影响。

## 变异与版本

VCF 需与对应基因组版本一致，REF 需匹配参考序列；基因组位点投影到转录本后用于避让。未提供或未覆盖研究材料的 VCF，不能支持“样本中没有 SNP”的结论。

同一实验应保留输入序列、参考版本、数据库路径、参数和任务证据。更换参考或数据库后重新检查候选特异性。
