# 快速开始

本软件用于 SYBR Green RT-qPCR 基因表达实验的引物设计与评估。输入靶标转录本或 cDNA 的 DNA 序列，得到候选引物对，再结合特异性、结构和实验结果选择 assay。

序列框允许小写 DNA、IUPAC 歧义字母、空格和换行。混入说明文字、FASTA 标题、数字或其他符号时，搜索和“保存序列”会提示无效字符所在行列，并选中该字符。“保存项目”可保留未完成原文草稿，便于下次继续。FASTA / GenBank 文件可通过“导入序列…”读取。

## 设计一对引物

1. 在左侧选择“添加序列”，或通过“导入序列…”读取 FASTA / GenBank。
2. 展开“靶标序列与引物输入”，填写靶标 ID 和序列，点击“保存序列”。序列使用 DNA IUPAC 字母，至少 40 nt；Forward 和 Reverse 均按 5′→3′填写。
3. 默认使用简单模式。需要设置表达目标、目标区域或反应体系时，在工作台右上角勾选“专业模式”，打开“设计条件”。CDS、外显子和多转录本策略需要对应参考注释。
4. 在“参考与特异性”配置物种参考项目及转录本、基因组数据库。数据库名称与版本应对应研究材料。
5. 返回工作台点击“Search · 搜索”。在 Search Criteria 中选择 Pairs，设置 F/R 搜索起点与末位、引物长度和产物范围，再点击“开始搜索”。专业模式可编辑 Tm、GC 与返回数量。坐标为模板正链的 1-based 坐标，包含末位；末位留空表示模板末端。
6. 点击“结果”查看候选表。综合分数固定在左侧，选中分数显示在结果标题旁；Tm、长度、GC、错配与发卡指标直接显示。专业模式的宽窗口右侧同步显示详细属性。双击候选或点击“编辑”进入编辑区。
7. 优先选择评分较高、证据完整且符合检测目标的引物对。分数范围为 0–100，在“质量报告”查看评分依据和证据覆盖；尚未完成的特异性检查显示“未检查”。点击“结构分析”检查选中候选的结构与热力学结果。
8. 勾选准备采用的候选，界面显示“勾选已自动保存”。已有项目写回原文件；首次使用会创建本机项目草稿。取消勾选也自动保存。需要指定文件名与位置时点击顶部“保存”。

## 智能推荐与工程统一参数

在 Search Criteria 点击“智能推荐参数”。软件用当前模板和搜索类型进行真实试算，显示“推荐依据与试算结果”。点击“应用推荐参数”后，建议载入输入框；可以继续调整，再点击“开始搜索”。试算产生的候选用于评估参数，正式搜索结果随后进入任务记录。

优先检查常规 qPCR 条件：引物 18–24 nt、最佳 20 nt，Tm 58–62 °C、最佳 60 °C，GC 40–60%，产物 80–200 bp，返回最多 10 条。短模板会收窄产物范围；不足 60 nt 的成对设计会提示补充序列。当前反应浓度、结构限制、注释区域、变异与连接位点要求继续应用。

常规条件没有可保留候选时，软件依次试算最大 30 nt 的引物长度、30–70% 的 GC 范围，保留相同 Tm 与结构限制。这些是本软件的搜索回退策略，具体扩大项在报告中展示。试算均无候选时保留当前参数并给出诊断。试算未检查数据库特异性，正式结果还需要检查特异性及实验验证。

勾选“统一搜索参数用于本工程全部基因”，开始搜索后统一 Tm、GC、引物长度、产物长度、Tm 差及返回数量，包括已有的靶标单独参数。各基因的区域及反应浓度继续保留；新加入的基因使用工程公共参数。推荐只根据当前模板试算，各基因的可用候选数量由正式搜索确定。该选择会随工程保存和恢复。

遇到手动区域超出模板范围，可勾选“重新使用全模板范围”，清除本次包含、排除及 F/R 手动范围后重新试算。CDS、变异及末端避让策略仍执行；短模板也需检查专业模式中的两端避让长度。

## 继续设计下一个基因

当前基因选择完成后，点击左侧“添加序列”。输入区会展开，填写下一个基因的独立 ID 和序列再搜索。已有设计保留在同一项目中；点击左侧基因切换其当前模板最近一次结果，展开任务记录可查看历史候选。没有对应设计的基因显示空表，旧模板任务会标明“历史模板结果”。

各基因的原始输入草稿分别保留，切换回来继续编辑；未完成文字也能随勾选自动保存。单引物历史下拉框同步所属基因、F/R 方向和结果说明，旧模板搜索标明历史状态。

多个窗口编辑同一工程时，保存会检查磁盘版本。遇到冲突，本次修改保存为独立副本，原工程继续保留其他窗口的修改。查看提示中的副本路径，核对后可打开副本或保存到新的位置。

左侧“查看 / 恢复备份”显示压缩备份及占用。近期保留最多 10 份、50 MB，较早记录按月归档；完整历史保留，可通过“打开备份位置”转移归档文件以释放空间。恢复所选记录会打开独立工程，请点击顶部保存指定新文件。

查看结构、质量或特异性后，点击“候选表”返回当前任务列表；进入引物编辑区后，点击“结果”返回。查看某对引物与勾选导出是两个独立操作，表格左侧的复选框用于保留导出选择。

普通导出作用于整个项目的所有设计任务，默认启用“仅导出勾选项”。CSV 和 Excel 的 Primers 主表只包含勾选且未被发卡筛选排除的候选；取消该选项时包含各任务的全部保留候选，同一基因多次设计的结果也会包含。Excel 其他工作表保留完整检查记录。

## 搜索范围报错

“排除区域超出模板范围”对应专业模式“设计条件”中的排除区域，采用“起点,长度”格式。没有需要避开的片段时可清空；有排除要求时按当前基因的模板长度重新核对，起点 + 长度 − 1 不得超过模板末位。项目公共坐标可能不适用于长度不同的基因。F/R 搜索范围的末位留空表示该模板末端。

## 批量设计

导入多条序列后点击“批量设计”。运行中可暂停、继续或取消；已完成任务保留结果。左侧任务记录可查看每个靶标状态，对失败靶标重试，或对当前靶标放宽条件后生成新任务。

批量任务固定公共设计策略，每个基因从自己的记录读取覆盖要求。专业模式中“要求覆盖的参考转录本 ID”用于指定同一基因的参考转录本集合，保存序列后归属于当前基因；模板下方“预期转录本”用于数据库预期产物判定。失败重试仅使用当前模板最近一次任务状态，已完成的新设计不受旧失败历史影响。

批量完成后点击“智能导出 · 每基因一对”：软件使用当前模板最近一次任务，排除质量拒绝项、无有效评分项及高风险发卡，再选出每个基因评分最高的一对。先核对预览中的选出引物、未导出的基因及原因，再导出 Excel / CSV。已有 GeneId 或参考映射的转录本合并到同一基因；无映射的靶标各自导出。此功能保留手动勾选状态；Excel 包含完整筛选证据，CSV 同时生成智能导出记录表。

## 评估已有引物

在编辑区可只输入 Forward 或 Reverse，点击 Analyze 计算该引物的 Tm、GC、发卡和自二聚体；填写两条时还计算异二聚体。分析结果显示在编辑区，并保存到历史记录。继续修改序列会清空编辑区的当前指标，重新 Analyze 后更新。Apply 需要两条引物。

## 从模板选区构建引物

在靶标序列框中选中连续的 15–36 nt，右键选择“选区作为 Forward”或“选区作为 Reverse”。软件载入编辑区并分析。Reverse 自动转换为反向互补，最终序列保持 5′→3′。换行和空格不计入碱基坐标。选区含歧义碱基或长度不合要求时，界面会说明原因。

需要寻找另一条引物时，点击编辑区的 Search，选择固定 F 找 R 或固定 R 找 F。完整引物对准备好后，Apply 核对模板位置与产物。

## 编辑已有候选

选择候选后点击“Edit Primers · 编辑”，载入该候选的模板与条件。也可切换到编辑标签，直接填写 Forward 和 Reverse 的 5′→3′序列。修改后先点“Analyze · 分析”更新自身指标；点“Apply · 应用重算”与模板核对、重新检查坐标与特异性，保存为独立任务及修订。原候选和证据保留。不满足条件的引物仍显示可计算指标，并在质量报告中标记排除。

若替换碱基后与输入模板不再完全匹配，Analyze 仍可计算编辑序列的长度、Tm、GC、发卡、自二聚体、异二聚体和 ΔG。该分析不提供模板结合坐标或产物结论。结果随项目保存，可在“结构分析”页的记录列表重新查看。固定引物配对和 Apply 坐标重算要求引物在模板上有精确结合位点。

右键点击引物输入框可执行反向互补、仅反向或仅互补。方向转换会修改整条输入序列，转换后重新分析，确认最终订购序列为 5′→3′。

## 单引物与兼容配对搜索

Search Criteria 的 Search Type 选择 Sense 或 Anti-sense，在“单引物搜索”页查看长度、Tm、GC、坐标及发卡指标。选中一条后点 Edit Primers 或“载入并寻找配对”；在编辑区点击 Search，并选择 Compatible with Sense 或 Compatible with Anti-sense。固定引物保持原序列，另一条按产物、Tm 与结构限制搜索。单引物结果尚未完成成对产物及特异性检查；配对搜索后查看完整候选证据。

Both 分别生成两个独立列表，通过结果页上方列表切换方向及历史搜索。单引物搜索忽略扩增子长度；Pairs 生成引物对并应用产物长度范围。取消 Search Criteria 会保留原条件。

## 保存与窗口操作

- 勾选或取消勾选候选会自动保存整个项目及当前模板输入草稿，左侧下方显示保存状态和文件位置。尚未完成或含无效字符的原始序列输入会作为草稿保留，已经应用的模板与计算证据保持原记录。
- 本机草稿位于用户本地应用数据的 QpcrPrimerStudio/drafts 目录。下次启动会恢复最近保存的项目，也可通过“项目 → 恢复最近自动保存”恢复。
- 右上角“保存”或 Ctrl+S 可指定项目文件名及位置；Ctrl+O 打开项目。关闭窗口会等待进行中的自动保存完成。
- 模板和手工 F/R 原文按基因保存；点击“添加序列”可继续尚未提交的新基因草稿。同一基因有未提交模板时，载入候选或单引物配对会提示先处理模板。已有基因的 ID 不可静默覆盖另一基因。
- 主工程保存成功但最近恢复入口更新失败时，界面分别说明保存位置与恢复入口问题，可直接打开已保存的工程。
- 自动保存失败时显示失败状态，勾选仍保留在界面中，可用顶部“保存”选择可写位置。未显示保存完成时应继续处理保存提示。
- 有未保存修改时，关闭或切换项目会提供保存并继续、放弃修改和取消。
- 右上角可最小化、最大化或还原；拖动顶部空白区域移动窗口。
- 候选表会按空间调整列宽。窄窗口横向滚动查看右侧列，缩略文字可悬停查看。
- 点击“帮助”或按 F1 打开本指南，左侧搜索框可筛选包含关键词的章节。

## 从设计到实验

计算候选仍需通过实验检验。完成梯度或条件优化、单一熔解峰与扩增产物检查、标准曲线、NTC 和 −RT 对照后，将实测结果录入 MIQE 实验记录。软件预测不能替代这些验证。
