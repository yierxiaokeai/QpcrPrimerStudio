## 结果标签

点击左侧基因，输入序列和设计结果同步切换到该基因当前模板最近一次任务。没有对应任务的基因显示空表；模板更新后需要重新设计。任务记录可查看原始历史结果，旧模板任务会标明“历史模板结果”。

Tm、引物长度、发卡计算随 Primer3 设计默认启用。正常设计候选与输入模板精确结合，模板错配通常为 0/0；模板指纹不同、坐标不可核对或结合区域含歧义碱基时保留未核对状态。数据库错配需要参考数据库；自动特异性检查默认启用。列表数据库摘要选择末端错配最少、随后总错配最少的成对产物，完整数据库与其他命中查看特异性页。没有检出的成对产物仍受数据库覆盖和搜索限制影响。

“评分”列始终显示每对候选的 0–100 综合分数，选中分数也显示在结果标题旁。点击评分表头可按升序 / 降序排列。分数按已完成指标计算，缺失检查不计为通过；在质量报告查看证据覆盖和分项依据。

- 序列定位：查看引物方向、扩增子、外显子、CDS、UTR、变异和其他已提供注释，使用缩放条查看细节。
- 质量报告：查看每项评分、扣分或拒绝原因、覆盖范围与证据缺项。
- 结构分析：计算选中候选的发卡、自二聚体、异二聚体与 ΔG，检查 3′端互补风险。
- 特异性：查看 BLAST 原始命中、成对结合几何、预期及非靶向扩增证据。
- 实验记录：保存备注，录入 MIQE assay 信息。
- 任务日志：查看引擎输入输出、区域规划与失败原因，便于复现。

## 一键排除高风险发卡

点击结果标题旁的“排除高风险发卡”，按当前实验的 60 °C 退火温度核对候选。右键此按钮可修改筛选条件或清除筛选。原候选始终保留；勾选“显示已排除”可查看排除项，在质量报告查看具体证据。项目保存全部候选、阈值、反应体系与原始计算输出。导出的 Primers / CSV 主表仅包含保留项，Excel 的 Hairpin Screening 表保留完整筛选记录。

排除条件为：发卡结构 Tm ≥ 实际退火温度；或 3′末端碱基参与配对、发卡 Tm 位于退火温度下方的安全温差窗口，且 ΔG₃₇ 低于所设阈值。默认安全温差 5 °C 是可调整的筛选策略；默认 ΔG₃₇ 阈值为 −2 kcal/mol。仅有负 ΔG 不触发排除。ΔG 统一在 37 °C、各候选原设计反应体系下计算；这些规则用于候选优选，仍需实验验证。

依据：[IDT 发卡 Tm 判定](https://eupages.idtdna.com/pages/support/faqs/how-can-i-determine-if-a-hairpin-in-my-oligo-is-too-strong-to-allow-hybridization)；[Premier Biosoft 引物设计指南](https://www.premierbiosoft.com/tech_notes/PCR_Primer_Design.html)。采用 Primer3 ntthal 返回的预测发卡结构，未枚举所有可能折叠。

## 导出与批量优选

顶部“导出 Excel / CSV”默认仅导出手动勾选的候选，已触发发卡排除的候选不会进入主表。取消“仅导出勾选项”可导出全部未被发卡排除的候选；普通导出包含任务历史，核对候选所属模板与版本后再用于订购。

普通导出用于人工复核候选，可包含质量规则拒绝项；主表的 Accepted、Rejections、Warnings 和 TemplateSha256 明确标记质量状态、原因及模板版本。导出先写完整暂存，再安装结果；替换已有结果时保留同目录备份。

批量设计后点击“仅导出勾选项”旁的“智能导出 · 每基因一对”。软件使用各靶标当前模板最近一次任务，排除质量规则拒绝项、无有效评分项、目标结合错配/插缺或无法核对、非靶向产物及高风险发卡，再按综合评分最高选出一对。同分依次按原始排名、Primer3 penalty、靶标 ID、候选 ID 升序决定。已有 GeneId 或参考映射的多个转录本按基因合并；缺少映射时每个靶标 ID 独立处理。最近任务失败或取消时列出原因，当前模板没有任务时要求重新设计。

F/R 与目标模板须均零错配，含歧义碱基的结合位点会列为无法核对。已绑定数据库须完成检查，每个预期转录本至少有一组零错配、无插缺的完整 F/R 产物。未绑定数据库时只核对模板结合，并标注“转录本数据库未检查”。预览的“错配/未核对”列及说明、Excel 和 CSV 记录保留排除数量与具体原因。

预览分为选出的引物、未导出的基因和各靶标筛选记录。核对后选择 Excel 或 CSV：Excel 主表每基因一对，并附质量、来源和发卡筛选证据；CSV 同时写出“智能导出记录.csv”，包含未导出原因、阈值和计算证据。智能导出保留原候选和手动勾选状态。评分属于候选优选指标，仍需核对特异性证据并完成实验验证。

重新检查特异性会刷新评分和排除原因；智能导出核对评分所依据的证据，旧评分需要重新评估。搜索不完整时相关评分分项保持未知，已检出的非靶向产物仍触发排除。参考或注释无法核对时，候选明确提示重新设计，避免旧评分继续参与优选。

更换特异性数据库、预期产物 ID 或覆盖要求后，智能导出核对当前设置与历史证据的归属；失效的证据不能进入优选，预览给出重新检查或设计的原因。覆盖 ID 和数据库预期 ID 分别记录，指定覆盖集合不会覆盖手工填写的预期 ID。

特异性报告记录实际检查过的 F/R 序列指纹。旧工程报告缺少该指纹时保留原始命中证据，评分相关分项显示未知，智能导出提示重新检查；完成检查后可重新参与优选。

## gDNA 区分

A 级通常表示引物跨 exon–exon junction；B 级表示两条引物间存在可区分的基因组内含子；同外显子候选的污染区分能力较弱。具体内含子长度与等级解释以候选报告为准。

只有转录组数据时，基因组特异性不可用、gDNA 区分未知。预测未发现非靶向扩增依赖数据库覆盖与搜索条件。加工假基因等情况仍需审查，并设置 −RT 对照。

## 设计失败

先查看靶标任务状态、日志与拒绝原因。常见原因包括区域太短、缺少 CDS / junction 注释、参数冲突、强二聚体、非靶向扩增或末端变异。工具路径与数据库不完整也会导致检查失败。

“放宽并重试当前”生成独立任务并保留原记录。先确认序列、参考版本和坐标，再有依据地放宽相关条件。
